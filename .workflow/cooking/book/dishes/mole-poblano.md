# Mole poblano

Mexican · Main dishes. Defined in the [recipe catalogue](../../recipe-catalogue.md).

## Recipe

Ingredients: [mole paste](../products/mole-paste.md), [chicken stock](../products/chicken-stock.md), [poached chicken](../products/poached-chicken.md), [toasted sesame seeds](../products/toasted-sesame-seeds.md)

1. [Cooking pot](../stations/cooking-pot.md) (low): [fry](../techniques/frying.md) the paste, [simmer](../techniques/simmering.md) with stock for a long time
2. [Cooking pot](../stations/cooking-pot.md) (low): add chicken
3. [Prep counter](../stations/prep-counter.md): top with sesame
