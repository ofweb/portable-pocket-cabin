# PDR-0013: Production follows player progress

Status: Accepted

## Context

A resource can be hard to get at first and easy to get after player progress. Cabin production follows that progress.

## Decision

Production at higher tiers follows player progress through Survival mode. It replaces manual resource work only after that work becomes easy for the player. Players first do the work to get a resource before cabin production can replace it.

Coal production follows this rule. Players first progress to a point where coal is easy to get. Cabin coal production can then replace manual work to get coal.

## Rationale

Players first do the work to get resources through Survival mode. Production then replaces manual work that is easy for those players.

## Scope

This decision applies to resource production at higher tiers. It does not select tiers, costs, recipes, or controls. Shape must confirm the necessary player progress for each production capability. Balance work must keep that relationship.
