# Earlier milestone documents

These files preserve the earlier milestone specifications and acceptance history. [Direction](../../.workflow/direction.md) states the intended end state. The [Backlog](../../.workflow/backlog.md) records possible work without a delivery order.

Completed milestones retain their accepted behavior until later accepted work changes it. Draft milestones provide source material for feature-by-feature Shape work. A draft milestone is not an approved Feature Brief.
